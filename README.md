## 🚀 Featured Project

### 🌍 EAAYN: East Africa Agritech Youth Network

A complete multi-page website for the **East Africa Agritech Youth Network**, a youth-led network with chapters across East Africa.

- 🗺️ Chapter pages for each country, with "Join Chapter" buttons linking to WhatsApp community groups
- 🧩 Flexible chapter list that can grow as new countries join
- 📱 Fully responsive design built for mobile-first users

**Built with:** `HTML` `CSS` `JavaScript` `Tailwind`
